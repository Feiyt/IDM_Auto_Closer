# IDM Auto Closer

IDM Auto Closer 是一个轻量级 Windows 工具，可自动监控 Internet Download Manager（IDM）的下载状态，并在所有下载完成后自动关闭 IDM，无需修改 IDM 本身。

当前版本：**1.0.6**

## 功能特性

- 自动检测 IDM 是否正在运行。
- 监控 IDM 的文件读写活动，判断下载是否完成。
- IDM 下载完成并持续空闲约 10 秒后，自动关闭 IDM。
- IDM 尚未启动时自动等待，不影响正常使用。
- 单实例运行，避免重复启动多个程序。
- 无需安装，运行单个 EXE 文件即可。

## 使用教程

### 1. 准备 IDM

请先安装 IDM，并确保 IDM 可以正常启动和下载。

### 2. 启动程序

1. 从项目的 Releases 页面下载最新版本的 `IDM_Auto_Closer-Windows-版本号.exe`。
2. 双击运行下载的 EXE 文件。
3. 程序会在后台持续监控 IDM，无需进行其他操作。

### 3. 自动关闭

当 IDM 产生过实际下载活动，并且下载完成后持续处于低活动状态约 10 秒，程序会自动关闭 IDM。

程序不会因为 IDM 启动后一直没有下载活动就自动关闭 IDM，因此可以提前启动本程序。

### 4. 退出程序

如需停止监控，请在 Windows 任务管理器中找到 IDM Auto Closer 进程并结束任务。

## 注意事项

- 本工具通过监控 IDM 进程的文件读写活动判断下载状态，不直接监控网络流量。
- 暂停下载、等待连接、文件校验或下载队列中的任务可能被识别为低活动。
- 自动关闭前请确认 IDM 中没有仍需保留的下载任务。
- 建议在需要下载文件时启动 IDM，或让浏览器自动启动 IDM。
