
# IDM Auto Closer

IDM Auto Closer 是一个用 Go 语言编写的轻量级工具，可自动监控 Internet Download Manager (IDM) 的下载状态，并在所有下载完成后自动关闭 IDM，无需对 IDM 本身做任何修改。

当前版本：**1.0.6**

---

## 功能特性

- **自动检测 IDM 路径：** 自动从 Windows 注册表查找 IDM 的安装位置。
- **智能监控：**  
    - 后台常驻，自动等待 IDM 启动。
    - 实时监控 IDM 进程的 I/O 活动。
    - **空闲检测：** IDM 启动后必须先观察到实际 I/O 活动；之后当 I/O 速度低于 1KB/s 并持续 **10 秒**以上（多次检测确认），才判定为可能没有下载任务。
- **自动关闭：**  
    - 确认处于空闲状态后自动结束 IDM 进程。
- **单实例运行：**  
    - 防止重复启动多个本工具实例。
- **极致轻量：**  
    - 编译为单一可执行文件，资源占用极低。

## 使用方法

### 1. 环境准备

- 需先安装 Go 语言环境。
    [Go 下载地址](https://go.dev/dl/)
- 支持 Go **1.21 及更高版本**（以 `go.mod` 中声明的版本为最低要求）。

### 2. 编译

#### Windows 用户构建

- 非开发人员直接双击运行 `build.bat` 脚本。
- 脚本会自动读取 `main.go` 中的版本号并编译 Windows 版本。
- 本地运行 `build.bat` 时不会添加 `-H=windowsgui`，便于查看控制台日志。
- GitHub Actions 发布正式版时使用 `build.bat release`，此时才会添加 `-H=windowsgui` 隐藏控制台窗口。

### 3. 运行

- 直接运行生成的 `IDM_Auto_Closer-Windows-1.0.6.exe`（实际文件名中的版本号以当前构建版本为准）。
- 程序会自动在后台运行。
- 可通过任务管理器查看进程。
- 如需退出，请在任务管理器中结束该进程。

---

### 4. 本地测试

- 双击运行 `test.bat`，或在命令行执行 `test.bat`。
- 脚本会依次运行 `go test`、`go vet` 并构建测试程序。
- 所有测试构建产物输出到 `test` 文件夹，不会生成在项目根目录。

## 目录结构

- `main.go`：包含程序版本定义
- `build.bat`：编译脚本
- `test.bat`：本地测试脚本

---

## GitHub Actions 发布

- 发布工作流会缓存 Go 模块，避免重复下载依赖。
- 工作流设置了 10 分钟超时，并会保留 7 天的 artifact 备份。
- `build.bat` 不包含 `pause`，可安全用于 CI。
- Release 最终只上传当前版本的唯一 Windows EXE。

## 注意事项

- 本工具通过监控 IDM 进程的 I/O 活动（而非直接监控网络流量）判断下载状态。
- 程序不会因为 IDM 启动后一直没有 I/O 活动就自动关闭 IDM；必须先观察到活动，随后持续空闲约 10 秒才会触发关闭。
- I/O 活动只能近似反映下载状态。暂停、等待连接、校验或队列中的任务可能被识别为低活动，自动关闭前请确认 IDM 中没有仍需保留的任务。
- 建议在需要下载文件时再启动 IDM（或让浏览器自动唤起 IDM），本工具会在后台自动接管监控。
